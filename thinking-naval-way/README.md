# Thinking Naval Way

> 以高信號、第一性原則與槓桿思維，分析使用者明確提供的內容並提出一個具體行動。

| 項目 | 內容 |
| --- | --- |
| 狀態 | 草稿 |
| 版本 | `0.1.0` |
| 最後更新 | `2026-09-05` |
| 相容環境 | 支援載入本 repository skills 的 AI agent |

## 目的

此 skill 把使用者指定的文字、網址或檔案，轉為精簡的信號判斷、五維第一性原則分析與單一行動建議。適用於評估技術、商業資訊或內容是否值得投入注意力與行動；不適用於未經使用者指定範圍的主動蒐集或外部系統操作。

## 原理與特殊設計

它透過槓桿、急迫性、發布者動機、認知模型與傳播價值五個濾鏡，優先保留可形成特定知識或實際決策的資訊。對純炒作、融資宣傳、同質化套話與恐懼行銷採取早期終止：用一至兩句指出商業動機並略過，不用冗長分析來放大雜訊。

它僅讀取使用者明確指定的內容，且不會未經確認寄信、修改行事曆或刪除檔案。

## 內容與檔案結構

```text
thinking-naval-way/
├── README.md
└── SKILL.md
```

## 前置需求

- 使用者提供欲分析的文字、網址或檔案。
- AI agent 可讀取該使用者指定的內容。

## 使用方法

### 安裝或放置

將整個 `thinking-naval-way/` 目錄放進 AI 工具的 skills 目錄，或讓工具直接載入此 repository。使用時 AI 必須先閱讀 `SKILL.md`。

### 最小可用範例

提供一段文章或連結，並要求：「請用 thinking-naval-way 分析這段內容。」

skill 會依固定結構輸出信號判斷、核心本質、五維濾鏡透視與一個行動建議；若判定為雜訊，會簡短說明後結束。

### 驗證方式

- 確認輸出依 `SKILL.md` 的指定結構呈現。
- 確認低密度雜訊只得到一至兩句原因，不延伸冗長分析。
- 確認沒有讀取未指定內容或執行任何外部變更。

## 設定與進階用法

目前無。使用者可指定不同文字、網址或檔案作為分析範圍。

## 限制與安全考量

- **限制：** 此為決策與思考框架，不是事實查核、投資建議或法律／醫療意見。
- **成本／速率限制：** 取決於讀取指定內容與執行 AI 模型的環境。
- **隱私與敏感資料：** 僅處理使用者明確指定的內容；不要提供未獲授權分享的機密資訊。
- **可能的不可逆操作：** 無；skill 明確禁止未經確認的寄信、行事曆變更與刪檔。

## 疑難排解

| 現象 | 可能原因 | 解法 |
| --- | --- | --- |
| 分析範圍不明確 | 未指定要讀取的文字、網址或檔案 | 明確提供並指名欲分析的內容。 |
| 輸出過長 | 原始內容含有低密度宣傳 | 要求套用 skill 的雜訊判定與早期終止規則。 |
